# Business Model Canvas

| Bloque | Hipótesis inicial |
| --- | --- |
| Segmentos | Cooperativas salineras, distribuidores y marcas. Laboratorios y verificadores como usuarios colaboradores |
| Valor | Saldo e historial por lote, evidencias organizadas y consulta comercial compartible |
| Canales | Entrevistas directas, redes productivas, demos y referidos |
| Relaciones | Incorporación asistida, soporte de piloto y autoservicio para compradores |
| Ingresos | Suscripción, licencia, alta, multiempresa e integraciones |
| Recursos | Equipo, software, infraestructura, datos de lote y estándares |
| Actividades | Captura en campo, conciliación, verificación, capacitación y soporte |
| Alianzas | Cooperativas, compradores y laboratorios por validar. Copernicus y Fuji son fuentes e infraestructura |
| Costos | Desarrollo, operación, custodia documental, procesamiento, gas y soporte |
