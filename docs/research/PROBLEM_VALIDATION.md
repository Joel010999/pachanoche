# Validación del problema

| Hipótesis | Prueba | Evidencia buscada |
| --- | --- | --- |
| El comprador pide origen | Revisar recepción reciente | Requisito concreto y consecuencia de incumplir |
| La cooperativa pierde tiempo con lotes | Observar pesaje y conciliación | Minutos, errores y registros duplicados |
| Trazabilidad habilita mercados | Comparar requisitos de dos canales | Canal que exige evidencia verificable |
| Existe presupuesto | Preguntar quién autoriza y cómo compra | Responsable y propuesta de piloto evaluable |
| Interesa la sal artesanal diferenciada | Mostrar fichas equivalentes y medir elección | Atributos considerados en una decisión |
| Faltan datos para recepción | Caminar por remito e informe de muestra | Campos y documentos mínimos |

Registrar casos, objeciones y frecuencia. Las entrevistas y pilotos siguen pendientes. Usar evidencia observada para revisar requisitos y evitar extrapolar desde una sola organización.
