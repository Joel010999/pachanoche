Datos demo: lotes, coordenadas declaradas, pesos, documentos y organizaciones son sintéticos. Conservar el STAC Item para cualquier escena real que se incorpore, con atribución y método de procesamiento. Cargar resultados químicos reales únicamente con informe y permiso. Toda interacción comercial descrita es hipotética hasta validarla.
