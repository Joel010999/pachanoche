# Alternativas y competencia

| Alternativa | Criterio para comparar |
| --- | --- |
| Planillas, remitos y mensajería | Costo marginal bajo, facilidad de adopción y esfuerzo de conciliación |
| Trustwell FoodLogiQ | Evaluar cobertura de trazabilidad alimentaria, incorporación y costo comercial |
| TraceGains | Evaluar gestión de proveedores y documentación frente al flujo de lotes pequeños |
| Implementación propia basada en EPCIS | Evaluar interoperabilidad, inversión inicial y esfuerzo de integración |

La ventaja propuesta es un flujo liviano para salinas con masa conciliable y evidencia territorial contextual. Validarla con un lote de punta a punta y medir costos con el mismo volumen y requisitos. No se verificaron precios ni se hizo una evaluación práctica de proveedores.
