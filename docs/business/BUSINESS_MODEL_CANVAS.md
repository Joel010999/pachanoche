# Business Model Canvas

| Bloque | Hipótesis de trabajo |
|---|---|
| Segmentos | Turistas y aficionados B2C, guías/agencias/alojamientos B2B. |
| Propuesta | Decidir cuándo y dónde observar con trazabilidad y conectar con una actividad reservable. |
| Canales | Alojamientos, buscadores, operadores, fotografía y oficinas de turismo. |
| Relación | Autoservicio en planificación, soporte para cancelaciones y acompañamiento a prestadores. |
| Ingresos | Comisión por reserva completada, SaaS y API comercial. |
| Recursos | Motor por objetivo, catálogo de lugares, operadores validados y capacidad técnica. |
| Actividades | Calibrar recomendaciones, verificar oferta, asistir reprogramaciones y mantener datos. |
| Socios objetivo | Prestadores, alojamientos, comunidades, administradores de sitios y organizaciones turísticas. |
| Costos | Desarrollo, infraestructura, datos, cobros, soporte, visitas y adquisición. |

El canvas describe hipótesis previas al piloto. La demo utiliza experiencias ficticias.
