# Estrategia comercial

Entrevistar por separado a productores, distribuidores, marcas y laboratorios. Solicitar ejemplos redactados de documentos y observar una conciliación real. Elegir una cadena voluntaria con un comprador dispuesto a definir sus criterios de recepción y compartir la carga de incorporación.

Proponer un piloto acotado con dos ciclos de entrega, una planilla comparativa, reglas de publicación y una persona responsable por organización. Medir tiempo de alta, tiempo para obtener evidencias, diferencias de saldo y porcentaje de lotes con documentación completa. Presentar opciones de precio con igual alcance y registrar quién puede aprobar presupuesto. Continuar si se observa uso repetido y existe una propuesta comercial aceptada para evaluación.
