# Roadmap

| Etapa | Hito de salida |
|---|---|
| Demo | Verificar recorrido en el equipo de proyección, incluida degradación sin red. |
| Validación | Auditar elevaciones y horizontes, revisar permisos para sitios candidatos, comparar efemérides con JPL y observar noches con prestadores. |
| Piloto | Homologar al menos un corredor con oferta confirmada. Ensayar inventario, reprogramación, soporte y panel con cuentas por operador. |
| Comercial | Aprobar condiciones, privacidad y operación. Integrar cobros, devoluciones y conciliación, añadir caché meteorológica y datos VIIRS cuantitativos. |
| Expansión | Replicar taxonomía y pipeline por región, evaluar calidad y acuerdos locales antes de publicar. |

Para el panel futuro, los operadores editan experiencias y precios, abren turnos, consultan reservas, registran reprogramaciones y ven conversión y ocupación. Control de acceso por operador y bitácora para cada cambio comercial.
